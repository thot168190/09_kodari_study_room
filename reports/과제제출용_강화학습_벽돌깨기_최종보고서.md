- **최종 공식 최고 기록**: **`39.2개` (전체 4위 / 기본 두뇌 26.6개 대비 +12.6개)**
- **초기 상태 대비**: 9.4개 ➔ 33.6개 ➔ **39.2개** (+29.8개 수직 상승)

## 1. 실험 배경 및 초기 문제 진단
- **기본 설정의 한계**: 코랩 기본값(`씨앗=0, 은닉=64`)으로 학습 시 많은 수강생이 **36.8개**에 묶이는 현상 발생. 패들이 공을 중앙으로만 받아쳐 수직 왕복 운동을 반복하다가 3,000스텝 타임아웃으로 끝나는 것이 원인이었음.
- **체급 과부하 실험**: 은닉 노드를 128로 늘렸더니 연산 시간이 8분 이상으로 급증하고, 20만 걸음이라는 제한된 스텝 내에 수렴하지 못해 성능이 급락하는 **과적합(Overfitting)**을 경험함.

---

## 2. 점수를 폭등시킨 4대 핵심 튜닝 비법 (전략)

### ① 최적 체급(미들급) 선정 (`은닉 = 64 ~ 96`)
- 미니 벽돌깨기 환경(상태 8개, 액션 3개)에는 128처럼 무거운 두뇌보다, **64~96 사이의 날렵한 체급**이 20만 걸음 내에 가장 빠르고 정확하게 수렴함을 확인.

### ② 각도 생성의 비밀 (`씨앗(Seed)` 변경)
- `씨앗 = 3` 및 `씨앗 = 7`로 난수표를 변경하여 초반 리플레이 버퍼에 **"패들의 끝(모서리)으로 공을 깎아 쳐서 대각선 각도를 벌리는 경험"**을 주입.
- 이를 통해 공이 상단 벽돌 숲을 뚫고 들어가 한 번에 대량 파괴하는 모서리 타법을 체득함.

### ③ 최고점 낚시질 (`체크포인트 평가 주기 5,000걸음 단축`)
- 기존 2만 걸음 주기(총 10회 검사)를 **5천 걸음 주기(총 40회 검사)**로 4배 촘촘하게 변경.
- DQN 특유의 정책 흔들림 속에서 **피크를 찍는 찰나의 전성기 순간(40점대 대박 판)**을 놓치지 않고 금고(`최고_두뇌`)에 즉시 보존함.

### ④ 수비 안정성 보강 (`탐험기간 = 0.45`)
- 입실론 감쇄 기간을 소폭 늘려 초반 억까(낙하 실수)를 방지하고 5판 평균의 편차를 줄임.

## 3. 최종 적용 하이퍼파라미터 코드

```python
총걸음 = 200_000     # 대회 규정 엄수
은닉 = 96            # 과적합 없는 황금 체급 (64~96)
학습률 = 5e-4        # Adam 옵티마이저
감마 = 0.99          # 장기 보상 할인율
탐험기간 = 0.45      # 수비 안정성 강화
씨앗 = 3 / 7 / 1     # 대각선 각도 공략 황금 시드 라인
# if 걸음 % 5_000 == 0:  # 5천 걸음마다 최고점 낚시질 적용
```

## 4. 실습을 통해 깨달은 강화학습의 본질 (소감)
1. **씨앗(Seed)의 중요성**: 동일한 하이퍼파라미터라도 초반 어떤 우연한 경험이 버퍼에 쌓이느냐에 따라 전혀 다른 스타일의 두뇌로 성장한다는 것을 체감함.
2. **모델 크기와 데이터의 균형**: 무조건 신경망이 크다고 좋은 것이 아니며, 주어진 학습 스텝에 딱 맞는 최적의 체급이 존재한다는 것을 실패 실험(128 노드)을 통해 깊이 깨달음.
3. **평가 주기의 가치**: 강화학습 모델은 지속적으로 진동하므로, 고점을 낚아채는 세밀한 체크포인트 관리가 실전 성능을 결정짓는 핵심 무기임을 확인함.
