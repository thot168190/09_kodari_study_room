## ⚡ 코다리 부장의 실시간 빌드 가이드

1.  **빌드 및 복사 명령어 (코다리가 수정 후 자동 실행 완료):**
    ```bash
    npm run build && rm -rf dist-final && cp -r dist dist-final
    ```
    *   이 명령어가 가동되면, 코다리가 고친 코드가 컴파일되어 최신 버전의 파일들이 자동으로 `dist-final` 폴더에 안착합니다.
2.  **대표님의 실서버 반영 액션:**
    *   배포 사이트(닷홈 웹 FTP 등)를 여시고,
    *   로컬의 **`dist-final`** 폴더 안에 들어있는 아래 파일들을 선택하여 서버의 파일 업로더기(FTP)를 통해 그대로 덮어쓰기 하시면 즉각 반영 완료됩니다!
        *   `index.html` (메인 홈페이지)
        *   `demo.html` (체험판 페이지)
        *   `terms.html` (이용약관)
        *   `privacy.html` (개인정보처리방침)
        *   `assets/` (디자인 이미지/CSS/JS 번들 파일 폴더)
